# 使用正交状态机而不是单一文档状态

文档审核继续使用 `Draft -> PendingReview -> Published -> Archived` 四态，不增加解析中、失败、可检索、软删除等技术状态。文件安全、入库任务、任务步骤、关键词/向量/图谱投影、索引发布、删除保留、问答运行和评测运行分别保存状态；问答的运行状态、当前阶段和最终结果也分开记录。删除按目标拆分为 `deletion_request/deletion_target`，索引跨库发布由 `index_activation_intent` 驱动，SSE 可展示事件由 `answer_run_event` 持久化。

文档是否可检索由审核、文件可用性、删除状态、有效期、必需投影、当前激活的索引发布和 ACL 共同派生，不提供直接修改 `searchable` 的通用接口。所有状态迁移必须通过领域命令执行，使用乐观并发控制并记录前后状态、操作者、原因、时间、Trace ID 和错误码。能力类型可以扩展，稳定生命周期状态使用受约束枚举。

该设计增加了表和状态迁移规则，但避免单一大枚举产生非法组合，也使连接器、GraphRAG、灰度索引、合规删除和 Agentic Retrieval 可以作为新增投影或运行阶段接入，而不改写文档主生命周期。
