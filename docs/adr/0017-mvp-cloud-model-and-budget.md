# MVP 使用阿里云百炼和受控模型预算

流程验证 MVP 通过 OpenAI-compatible `ModelAdapter` 接入阿里云百炼，分别调用 Chat、Embedding、Reranker 和高风险引用验证能力。业务模块不得直接导入百炼 SDK，也不得把具体模型名称写入领域数据模型；模型名称、地域、超时和路由策略由环境配置提供。

当前只允许合成或严格脱敏数据进入云模型执行区。首月模型预算上限为 500 元，并同时设置单次 Token 上限、每日问答/评测次数上限、总调用量和费用告警。达到预算后停止离线评测任务；在线请求返回受控的服务不可用或仅证据结果，不静默超支，也不自动把敏感数据降级发送到云端。
