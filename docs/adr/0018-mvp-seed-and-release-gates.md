# MVP 使用虚拟客服工单 SaaS 和分层验收门禁

知识种子集围绕一个虚构的企业客服工单 SaaS 构建，覆盖套餐、版本、地区、账号、权限、退款、API、错误码、故障处理和标准话术。首期规模约为 30 份产品资料、100 条合成工单、10 条标准话术和 50 道人工可检查的黄金题。

MVP 的硬门禁是：越权证据泄漏为 0；上传、解析、索引、检索、引用、拒答、审核和回滚主链路可运行；引用可以回跳到原文位置；无依据问题必须拒答或标记不确定；50 道黄金题可以在固定版本上重复运行。Recall@5 0.92、引用覆盖率 0.96、忠实度 0.95 和 P50 1.2s 是候选目标，必须在建立真实基线并明确测量口径后，才转为正式发布门禁。
